# EXP-016 — native Quick Session automatic overlay dismissal

Status: rejected mechanically on 2026-08-25.

This continuation experiment tested whether native Quick Session could remove
its second focus gesture by requesting a foreground managed-pane landing and
dismissing the Station overlay only after that landing returned
`{ kind: "success", landed: true }`. Deliberate New Session, Fork, notices,
failures, and non-landing results retained the overlay.

The prediction and keep rules were registered before the control binary or
candidate implementation was built:

- ten safe Ctrl-O control runs and ten safe automatic candidate runs;
- candidate Enter-to-input-ack median/p95 at most 200/350ms;
- candidate p95 at least 25% below the fresh control;
- automatic overlay-dismissal-to-input-ack p95 at most 100ms;
- no dismissal input byte in candidate runs;
- every named command/session/PTTY, canonical, input, inventory, process,
  stderr, phase, and root-removal predicate true.

## Results

| Boundary | Ctrl-O control median/p95 | Automatic candidate median/p95 |
| --- | ---: | ---: |
| Enter → input acknowledgement | 220/2348ms | 196/358ms |
| Focus/automatic dismissal → input acknowledgement | 41/294ms | 24/154ms |
| Overlay dismissal itself | 25/84ms | 0/0ms |
| Input write → acknowledgement | 15/209ms | 24/54ms |
| Enter → Host ready | 148/1203ms | 144/304ms |

The candidate improved Enter-to-input-ack median by 11% and p95 by 84.8%, and
all twenty runs were safe. It nevertheless missed the fixed 350ms absolute p95
by 7.8ms, missed the 100ms dismissal-to-input p95 by 54ms, and missed its
300ms prediction by 58ms. The candidate was therefore reverted without
weakening the rules after observing the result.

The remaining tail is not overlay rendering: the automatic overlay was already
gone while one Host child was not yet ready to acknowledge input. The next
question is whether native managed launch can expose bounded child-input
readiness before successful foreground landing, without coupling dashboard
policy to Host or harness mechanics.
