# Philosophy

## 1. The Terminal Is the Best Place for Agentic Engineering

Agents already work beside the code, shell, Git, and developer tools. Station
stays terminal-native so agentic engineering happens where engineering happens.

## 2. Agents Are Capable Enough to Work Independently

Agents should not need another system constantly steering or interpreting their
work. This is why Station just observes: it preserves context, reports status,
and surfaces the moments that need a person.

## 3. Make Room for Agent-Forward UX

Agentic engineering does not need to inherit every interaction pattern from
older developer tools. Station favors experimental, agent-forward experiences
when they make parallel work clearer and more natural.
